# 👋 Welcome to SpamBlock

### Block the unwanted. Protect what matters.

SpamBlock is an Android mobile security application designed to help protect users from unwanted phone calls, suspicious SMS messages, and potentially dangerous links.

Our mission is to make everyday mobile security simple, accessible, and trustworthy while giving users more control over their phone communications.

---

## 🛡️ Mobile Protection with SpamBlock

### 📞 Unwanted Call Protection
Take greater control over incoming calls and protect yourself from unwanted and potentially suspicious phone numbers.

### 💬 Suspicious SMS Protection
Recognize suspicious text messages and become more aware of potentially harmful messages.

### 🔗 Risky Link Protection
Identify potentially dangerous links encountered online and make more informed decisions before opening them.
